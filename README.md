# Mharo AGI • final Netlify build

This package contains:
• the latest Mharo AGI page
• Shayad audio at 30% volume
• anonymous page-open and TOUCH ME tracking
• private activity dashboard
• Netlify Functions + Netlify Blobs

IMPORTANT:
For tracking, deploy the whole project through a Netlify project/repository or Netlify CLI.
A plain static drag-and-drop of only the public folder will not deploy the Functions.

Dashboard:
https://YOUR-SITE.netlify.app/dashboard.html

Set this Netlify environment variable:
DASHBOARD_TOKEN = your private dashboard password

The visitor is not identified by name. Tracking records anonymous session activity.
